# Reporting security issues

If you discover a potential security issue in this project, please do **not** create a public GitHub issue.

Notify AWS Security via the [vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/)
or directly via email to aws-security@amazon.com.

This repository is a prototype and is not intended for production use. See [SECURITY-NOTES.md](SECURITY-NOTES.md)
for the security controls it implements and their known limits, and [THREAT_MODEL.md](THREAT_MODEL.md) for the
threat model.
